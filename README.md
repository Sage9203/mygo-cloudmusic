# MyGo CloudMusic
[![FOSSA Status](https://app.fossa.com/api/projects/git%2Bgithub.com%2FSage9203%2Fmygo-cloudmusic.svg?type=shield)](https://app.fossa.com/projects/git%2Bgithub.com%2FSage9203%2Fmygo-cloudmusic?ref=badge_shield)


一个简洁的第三方网易云音乐桌面客户端。

这是旧 [MyGo CloudMusic](https://github.com/egoist/mygo-cloudmusic) 的**非官方维护分支**，与原作者当前开发的 MyGo Music 分开维护。

[下载试用版](https://github.com/Sage9203/mygo-cloudmusic/releases) · [反馈问题](https://github.com/Sage9203/mygo-cloudmusic/issues)

## 功能

- 扫码登录、搜索歌曲、浏览和管理歌单。
- 每日推荐、私人 FM、播放队列和歌词翻译。
- 按账号权限播放高音质、无损及 Hi-Res 音源。
- 歌曲缓存、下一首预加载和音量均衡。

目前提供 **Windows x64** 版本。音乐能否播放、可用音质取决于账号权限和歌曲本身。

## 使用

1. 在 [Releases](https://github.com/Sage9203/mygo-cloudmusic/releases) 下载 Windows 便携包。
2. 完整解压，运行 `MyGo CloudMusic.exe`。
3. 使用网易云音乐 App 扫码登录。

升级前请先从托盘完全退出旧版。此前试用版的登录和设置可继续使用。

默认的共享音频模式适合边听歌边使用其他程序。独占模式可能使游戏或其他应用暂时无声，需要时再开启。音质和输出格式说明见 [音频输出](docs/AUDIO_OUTPUT.md)。

## 当前限制

当前为预发布试用版，程序尚未签名。播客自动字幕暂不可用。可在设置中启用自动检查更新，下载和安装由用户操作，其他操作系统尚未完成运行验证。

打开「设置 → 更新」可手动检查版本。发现新版本后，可从 GitHub 发布页查看完整说明并下载。
