# 数据与网络行为

本程序按账号已有权限访问网易云服务，不读取官方客户端的登录状态，不提供绕过付费或版权限制的功能。

- 生产版登录会话使用系统凭据存储；Windows 为凭据管理器。开发模式可能把会话写入开发数据目录。请勿分享这些文件。
- 设置、播放队列和进度、音频缓存等保存在本应用数据或缓存目录。缓存包含音乐文件，队列和进度会反映听歌记录，不应提交到仓库或作为故障附件上传。音源 URL 不写入音频缓存的元数据 JSON。
- 联网用于登录、账号与音乐信息、封面、歌词和音频等网易云服务请求。GitHub 仓库和网页链接只在使用者主动打开时由浏览器访问；本版未启用自动更新、崩溃报告或统计上传。
- 播客本地转字幕的下载与运行入口仍停用，不自动下载模型。
- 程序不会修改系统代理、DNS、路由或系统音频默认格式。独占输出为可选设置，使用时可能影响其他程序发声。

公开源码和发布包只包含项目代码、许可证、构建文件和测试素材，不包含使用者的现有应用数据。此说明不代表第三方服务不会记录正常服务请求。
