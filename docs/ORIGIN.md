# 来源与致谢

本项目是 [egoist/mygo-cloudmusic](https://github.com/egoist/mygo-cloudmusic) 的非官方维护分支。恢复的源码来自 [hyoban/mygo-cloudmusic](https://github.com/hyoban/mygo-cloudmusic)，对应提交 `b13f52a2a2ff0746502b85b9c4c7fa1e86a1c385`。保留原作者及第三方署名，沿用 AGPL-3.0。

- [MyGo](https://github.com/egoist/mygo)：原生界面与音频基础框架。
- [MyGo Music](https://github.com/egoist/mygo-music)：参考随机播放、日语歌词字形和高窗口布局的修复思路，对应提交 [aabab000](https://github.com/egoist/mygo-music/commit/aabab0008cf60b5c31632151930931f5905c00e0)、[e67d7066](https://github.com/egoist/mygo-music/commit/e67d70666de14f12adea669e2a246c5e48d81da2)、[32499f0a](https://github.com/egoist/mygo-music/commit/32499f0acf6058c2fd3fe7b69874a5d6bf608571)。
- [Cloudy](https://github.com/nya-owo/cloudy)：参考 FLAC 缓冲复用、隐藏播放页资源释放和流式文件存储的问题定位与实现思路，对应提交 [88b334ae](https://github.com/nya-owo/cloudy/commit/88b334aeeabc98a1d25f5fb6d6c87999b463cf17)、[dc90274b](https://github.com/nya-owo/cloudy/commit/dc90274bf946abe5cda2e9c4dbd5f409a6c823bc)、[f2f57897](https://github.com/nya-owo/cloudy/commit/f2f578979f164e4373c4c66fa05ca0bc647296a4)。

- 音量滚轮步进与回归测试参考 [MyGo Music 5a5906e9](https://github.com/egoist/mygo-music/commit/5a5906e9e9d43b0bf5dff5bb2cc8d220279e0327)，测试使用本项目的中文控件标签。
